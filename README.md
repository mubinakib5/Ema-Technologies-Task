## 🧑‍💻 Getting Started

To run this project locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/mubinakib5/Ema-Technologies-Task.git
   
2. **Navigate to the project directory**:
```bash
  cd portfolio
```

3. Install dependencies:
```bash
  npm install
```

4. Run the development server:
```bash
  npm run dev
```
